# Mark
The highlighter: a `marigold-soft` band behind ink, like a pen stroke across the line.

- Use it on at most one passage per essay, the sentence a reader should leave with. It is the site's signature, and it stops reading as one if it's used everywhere.
- It also sets text selection colour and the active nav item, so it already feels native.
- Never put it on a heading or a link.
