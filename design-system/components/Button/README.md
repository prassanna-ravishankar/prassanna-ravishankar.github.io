# Button
Mono-labelled buttons for the few actions the site has: subscribe, copy, listen, view repo.

- `quiet` (default): a `rule-strong` outline with `ink` text. `primary`: solid `indigo` with `on-indigo` text, at most once per page. `text`: an inline `indigo` link-button.
- Pass `href` to render a link with the same look.
- Labels are a verb first in sentence case: "Subscribe by RSS", "Listen on Spotify", "View on GitHub". No trailing arrows.
