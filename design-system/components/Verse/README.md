# Verse
A poem set for reading: generous leading, a line number in the margin every fourth line, and stanzas separated by `space-8`.

- Provide `stanzas` as an array of arrays of lines, an optional `title`, and `numberEvery` (default 4; set it high to hide numbers).
- Lines never justify or hyphenate. Long lines wrap with a hanging indent, so a wrapped line can't be mistaken for a new one.
- No drop caps, no decorative ornaments, no background image behind the text. A hero image, if any, goes above the title.
