# Logos

The mark is a lowercase IBM Plex Mono "p" (600) followed by the marigold recent-activity dot from the log. It reads as "prassanna." mid-sentence: the start of the domain and a sign that something is live. The glyph is outlined, so the files need no font.

- `favicon.svg`: the browser tab icon. A paper "p" and a marigold dot on an `indigo` tile with a 6/32 radius. Use it as the main favicon (`<link rel="icon" href="/favicon.svg" type="image/svg+xml">`). It holds up at 16px on light and dark tabs.
- `favicon-32.png`: the PNG fallback for browsers without SVG favicons.
- `apple-touch-icon.png` (180), `icon-192.png` and `icon-512.png`: square, full-bleed versions for home screens and the web manifest. The platforms round the corners, so the files don't.
- `mark-ink.svg`: the bare mark in `ink` with the marigold dot, for use on `paper` (slides, social cards, print).
- `mark-paper.svg`: the bare mark in `paper` with the marigold dot, for use on dark grounds.

Rules:
- Don't recolour the dot; it is always `marigold`. Don't put the mark on marigold or marigold-soft.
- Keep clear space of at least the dot's diameter on every side of the bare marks.
- Don't pair the mark with a serif version of the name. The wordmark is `prassanna.io` in mono (`wordmark`).
